# Experimentos

Guardar aquí tablas, resultados y gráficas de los experimentos controlados. Cada experimento debe incluir:

1. Hipótesis redactada antes de ejecutarlo.
2. Variable modificada (una sola a la vez).
3. Condiciones que se mantuvieron constantes.
4. Resultados obtenidos realmente.
5. Interpretación y conclusión.

No incluir resultados inventados ni evaluar repetidamente el conjunto de prueba reservado.
